# Since the first release: Blended Addressbar 1.6.1

This is a recap of changes since the initial release. The [full version-by-version changelog](../../CHANGELOG.md) records the intermediate releases, including settings that were later removed.

## Layouts and browser frame

- Supports Only Sidebar, Sidebar and Top Toolbar, and Collapsed Sidebar.
- Added frame spacing, corner radius, a rounding toggle that preserves the configured radius, and shadow presets.
- Added compact macOS window controls for Collapsed Sidebar.
- Kept split dividers square while rounding corners at the outer frame.
- Replaced the native split focus outline with a 1.5pt inset ring using Zen's accent color. The page and ring now share clipping and corner shape.
- Added a 0.5pt white inner highlight at 20% opacity to Minimal shadows. The outer shadow stays black at 20% opacity in both color schemes.
- Removed frame spacing and decoration for DOM fullscreen video; preserved rounded Only Sidebar frame corners in browser fullscreen.

## Page colors and window tint

- Added adjustable window tint using Zen's native theme backgrounds, including material-aware transparency on macOS.
- Improved foreground contrast for toolbar icons, bookmarks, site controls, and macOS window controls.
- Kept URL selection, addressbar popups, and bookmark folder menus on native colors.
- Improved internal-page handling to avoid carrying website colors into browser settings and other internal pages.
- Added a persistent page sampler and coalesced updates. Removed continuous loading polls and scroll-driven sampling.
- Improved tab switching by reusing in-session page colors and delaying fallback colors while fresh samples arrive.
- Added pixel-only color selection while Zen Boost is active.
- Removed cross-session site-color storage after it caused stale colors. Current page colors stay in memory and are cleared when the browser restarts.

## Bookmarks and loading

- Added an Only Sidebar bookmarks bar that appears on top-edge hover or stays visible through a setting.
- Adjusted its spacing, hover delay, color contrast, and loading-indicator placement.
- Added a separator toggle for the addressbar and bookmarks bar, including the Only Sidebar bottom separator.
- Unified Progress bar, URL bar glow, and Window edge controls for color, opacity, thickness, and shape. Zen's native loader remains available.
- Made URL bar glow the default custom loader and added a focus-color option.

## Installation and maintenance

- Updated Sine installation instructions, settings documentation, and marketplace preview metadata.
- Split reusable script logic into focused modules without adding dependencies or a build step.
- Added regression coverage for colors, preferences, layout contracts, and clipping geometry. Version 1.6.1 passes 57 Node tests; these do not replace visual checks in Zen.
